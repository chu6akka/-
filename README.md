# Анализатор русского текста

Ниже — пошаговая инструкция для начинающих, как скачать и запустить программу.

## 1) Скачайте проект

**Вариант A (через Git, если установлен):**

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_РЕПОЗИТОРИЯ>
```

**Вариант B (без Git):**

1. Откройте страницу репозитория в браузере.
2. Нажмите **Code → Download ZIP**.
3. Распакуйте архив.
4. Откройте папку с проектом.

## 2) Установите Python

Убедитесь, что установлен **Python 3.9+**.

Проверка в терминале:

```bash
python --version
```

Если команды нет — установите Python с сайта https://www.python.org/downloads/.

## 3) Установите зависимости

В папке проекта выполните:

```bash
./install.sh
```

Скрипт создаст виртуальное окружение `.venv` и установит нужные библиотеки.

> **Если вы в Windows:**
> 1. Откройте PowerShell в папке проекта.
> 2. Выполните команды вручную:
>
> ```powershell
> python -m venv .venv
> .\.venv\Scripts\Activate.ps1
> python -m pip install --upgrade pip
> pip install -r requirements.txt
> ```

## 4) Запустите программу (GUI)

После установки зависимостей:

```bash
source .venv/bin/activate
python gui_app.py
```

Откроется окно, куда можно вставить текст и нажать **«Анализировать»**.
После анализа можно нажать **«Сохранить в Excel»** и получить таблицу в формате `.xlsx`.

## 5) Запуск через консоль (если не нужен GUI)

```bash
source .venv/bin/activate
python text_analysis.py
```

Введите текст в консоли и получите таблицу в выводе.

## 6) Упаковка в EXE (Windows)

Откройте PowerShell в папке проекта и выполните:

```powershell
.\build_exe.ps1
```

Готовый файл появится в папке `dist\RussianTextAnalyzer.exe`.

## 7) Упаковка в EXE (Linux/macOS)

В терминале выполните:

```bash
./build_exe.sh
```

Готовый файл появится в папке `dist/RussianTextAnalyzer`.

## Частые проблемы

- **`ModuleNotFoundError`** — значит зависимости не установлены. Повторите шаг 3.
- **GUI не открывается** — убедитесь, что Python установлен корректно и запускается из терминала.
